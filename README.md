# РоссияГид

Демонстрационная версия путеводителя по России для самостоятельных путешественников.
Статичный сайт: один HTML-файл и папка с фотографиями.

## Открыть

После включения GitHub Pages сайт доступен по адресу:
**https://korneevgerman79-dev.github.io/russia-gid/**

Локально: открыть `index.html` двойным щелчком в браузере.

## Что внутри

- 26 регионов России, 108 мест с описаниями
- 6 регионов Кавказа с глубоким контентом: Дагестан, Чечня,
  Кабардино-Балкария, Карачаево-Черкесия, Северная Осетия, Калмыкия
- 140 фотографий в разрешении 1920px, без пережатия
- Логотип в шапке, иконка во вкладке браузера
- 9 фильтров, включая «Лёгкий доступ» и «Сложные»
- 12 маршрутов, планировщик поездки, сообщество
- Адаптивная вёрстка, тёмная тема

## Структура

```
.
├── index.html      весь сайт (~240 КБ)
└── images/         140 фотографий (.jpg)
```

Сайт автономен: нет запросов к внешним API, кроме шрифта Inter
с Google Fonts. Работает офлайн.

## Состояние данных

Названия, адреса и исторические факты сверены с источниками.

Цены, названия гостиниц и кафе, номера маршруток, телефоны —
**вымышленные**, для демонстрации структуры. Перед публикацией
каждый пункт нужно проверять.

Отзывы и счётчики («320+ маршрутов», «48 000+ отзывов») —
демонстрационные.

## Фотографии

Источник: Wikimedia Commons, преимущественно лицензии CC BY-SA.

**Перед публикацией** нужно либо проставить атрибуцию авторов,
либо заменить снимки на собственные или купленные.

Для шести локаций (Цой-Педе, Итум-Кали, Ведено, Тейское ущелье,
Элиста, остров Русский) на Commons не нашлось подходящих снимков —
стоят фото ближайших мест того же региона.

## Чего нет

- Серверной части — сайт статичный
- Реальной регистрации — формы это макеты
- Админки

Код — свободно. Фотографии — по лицензиям их авторов (см. выше).
